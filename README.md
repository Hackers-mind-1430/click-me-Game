# Click Game

A simple interactive browser game where players try to click a button that becomes increasingly difficult to catch as the levels progress. The game features smooth animations, dynamic movement, and responsive design.

## Features

* Progressive difficulty levels (Beginner → God Level)
* Cursor-aware button movement
* Animated UI and color-changing backgrounds
* Confetti celebration on completion
* Fully responsive and lightweight

## Tech Stack

* HTML
* CSS
* JavaScript (Vanilla)
